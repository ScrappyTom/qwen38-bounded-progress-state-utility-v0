This standalone experiment tests one bounded, model-authored control/progress
package at an authentic exact-residency boundary.

The selected seed-42 donor packet already contains the four governing source
documents, current patched candidate binding and relevant exact material, and
two model-selected exact focus results. No update is pending. The historical
actor nevertheless reread the just-delivered second focus exactly.

The experiment is staged:

1. reproduce the byte-identical control action;
2. ask a dedicated maintenance-mode invocation for a <=256-token plain-text
   progress state;
3. stop for direct audit and exact package preflight;
4. only then allow a separately frozen short actor treatment.

The package is lossy and non-authoritative. Exact task, evidence, candidate,
and literal tool results remain authoritative. This is one descriptive
trajectory, not a general progress controller or context architecture.
